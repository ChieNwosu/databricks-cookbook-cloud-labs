# Provenance standard

## Allowed

- Original prose written for these labs.
- Original code written for these labs.
- Links to upstream material by path and commit.

## Disallowed

- Copied book text.
- Copied upstream notebooks.
- Upstream datasets.
- Secrets of any kind (tokens, keys, passwords).
